| Date | Decision | Rationale and evidence | Consequences |
|---|---|---|---|
| 2026-10-25 | Replace the proposed RSSI, SNR, noise-floor, and packet-rate feature set with the seven raw measurements actually delivered by Module 1: peak frequency, peak level, noise level, SNR, band power, occupied bandwidth, and spectral flatness. | Proposal Section 3.2 permits the feature set to change subject to the features reliably provided by the upstream SDR module. The real Module 1 contract does not provide RSSI or packet rate. In the recorded evaluation, legacy J01 fired on 0 of 189 jamming rows, so retaining that rule would provide no measured detection value. Thresholds and normal states were therefore recalibrated from the first chronological half of the allowed known-signal groups. | Module 2 now has one measurement-only pipeline and one explainable narrowband rule. Ground truth remains outside runtime classification and is used only for chronological calibration grouping and scoring. Results are currently supported by one recording session and one legitimate device; deployment on a different radio requires fresh calibration and validation. |
